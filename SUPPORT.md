# Getting help

## Account, sending and API questions

The fastest way to get help is the **chat widget on [elasticemail.com](https://elasticemail.com)**. Our support team can help with your account, sending limits, deliverability, billing and API questions.

You can also email [support@elasticemail.com](mailto:support@elasticemail.com).

## Documentation and examples

- [REST API v4 documentation](https://elasticemail.com/developers/api-documentation/rest-api)
- [Elastic Email examples](https://github.com/ElasticEmail/elasticemail-examples) for transactional email, SMTP, webhooks, contacts and more
- Each SDK's README has a quick start and a full API reference

## Bugs in an SDK or tool

If you've found a bug in one of our SDKs, tools or integrations, open an issue in that repository using the **Bug report** template. GitHub issues are for bugs and feature requests only, not account support.

**Never paste your API key** into an issue, log or code sample.

## Security issues

Don't open a public issue. Follow [SECURITY.md](SECURITY.md).
