# ElasticEmail/.github

This repository holds the [Elastic Email organization profile](https://github.com/ElasticEmail) and the default community health files for every repository in the organization.

## What's here

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The README shown on the organization page |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to report bugs, suggest features and open pull requests |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Bug report and feature request forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Pull request checklist |

## How the defaults work

GitHub uses these files for any repository in the organization that doesn't have its own version. A repository's own `CONTRIBUTING.md`, `SECURITY.md` or issue templates always take precedence.

See [Creating a default community health file](https://docs.github.com/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) in the GitHub docs.
